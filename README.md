# 外食レコ

終了した外食記録アプリの主要機能を参考に、個人利用向けに独立実装したWebアプリです。

## 主な機能

- 行った店／行きたい店の登録
- 店名・住所・メモ・タグ検索
- 5段階評価、ジャンル、金額、日付、複数写真（最大10枚）
- 月別タイムライン、写真タイル表示
- OpenStreetMapによる店舗検索・地図表示・現在地表示
- JSONバックアップ／復元、CSV出力
- もぐレコ公式エクスポートCSVと画像ZIPの取り込み（項目名・ファイル名から自動判定）
- PWA対応（ホーム画面への追加、基本画面のオフライン起動）

## 起動方法

### 手軽な確認

`index.html` をブラウザーで開きます。店舗検索や地図は、ブラウザーの制約によりローカルファイルから動かない場合があります。

### 推奨

フォルダー内で簡易Webサーバーを起動してください。

WindowsでPythonがある場合：

```powershell
cd mogulog-web
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。

### 公開

このフォルダーをそのまま Netlify、Cloudflare Pages、GitHub Pages などの静的ホスティングへ配置できます。

## データ保存について

データはブラウザーのIndexedDBに保存されます。ブラウザーの履歴・サイトデータを消すと消失する場合があるため、「設定」からJSONバックアップを保存してください。

## 制限

- ログイン、複数端末同期、友達機能、公開SNS機能は未実装です。
- 店舗検索はOpenStreetMapの公開検索サービスを利用します。大量・連続検索には向きません。
- 位置取得は、Google Maps APIキーが保存されている場合はGoogle Placesを優先します。APIキー未設定時はGeolonia Community Geocoderを利用し、町丁目の代表点になる場合があります。
- もぐレコのCSV列名や画像ファイル名が想定外の場合、写真が自動で紐付かないことがあります。その場合もCSVの記録自体は取り込めます。
- 本アプリは非公式の独立実装で、元サービスおよび運営会社とは関係ありません。

## 地図がタイル状に崩れる場合

旧版ではLeafletのCSS検証値が誤っており、ブラウザーが地図用CSSを拒否する問題がありました。更新版で修正済みです。旧キャッシュが残る場合は、`Ctrl + F5`で再読み込みしてください。

## 位置情報について

- 緯度・経度が未設定の記録では、Googleマップのリンクを店名と住所で検索します。`null,null`にはなりません。
- Google Maps APIキーが設定済みの場合、Google Placesの店舗検索から位置を取得します。店舗画像と同じAPIキーを利用します。
- APIキーが未設定、またはGoogleで候補を取得できない場合は、Geolonia Community Geocoderへ切り替えます。この場合は町丁目付近の概算位置になることがあります。
- 個別ページを開いたとき、住所があれば位置情報を自動取得して地図を表示します。
- マップ画面の「位置を取得」から、既存の位置未取得データをまとめて補完できます。
- 旧版で位置取得に失敗した記録も、更新版で「位置を取得」を押せば再処理されます。
- 新しくもぐレコCSVを取り込む場合は、住所がある記録について位置取得を順番に試します。件数が多い場合は時間がかかり、Google Places利用分の料金が発生する可能性があります。
